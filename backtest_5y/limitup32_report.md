# 专项回测：三连板后持有到开板

> 策略原话：连续三个涨停，第四个交易日开始尝试买入，以开盘价买入（如果能买入的话），买入后第二天收盘不涨停就卖，如果涨停就继续持有，只要收盘不涨停就卖。

翻译成系统里的中文规则（可直接粘进页面第 4 步，策略库编号 **32**）：

```
当近3个交易日有3个涨停时买入；当收盘不涨停时卖出。
```

解析结果：买入 = `近3日涨停次数 == 3`；卖出 = `近1日涨停次数 == 0`（收盘不是涨停）。
生成的可执行代码：[`strategies/32_三连板后持有到开板.py`](strategies/32_三连板后持有到开板.py)

相对上一版「跌破 10 日线才卖」，这里改成**连板就拿、开板就走**。卖得更快，但仍是负期望。

## 口径

| 项目 | 设定 |
| --- | --- |
| 样本 | 全 A 股 5404 只、657 万根前复权日线 |
| 区间 | 2021-08-17 ~ 2026-08-17（1211 个交易日） |
| 涨停 | 涨幅达板块上限且收盘价 = 最高价：主板 ≥9.5%、创业板/科创板 ≥19.5%、北交所 ≥29.5% |
| 买入 | 第三个涨停当日收盘出信号，**次日（第四个交易日）开盘价**成交；一字涨停板买不到 |
| 卖出 | T+1 之后，第一个**收盘不是涨停**的交易日触发；页面引擎默认**次日开盘**成交 |
| 成本 | 手续费 0.5‰ + 滑点 0.5‰，双边，单次往返约 2‰ |
| 度量 | 信号级等权：每个买入信号都等额下单 |

「买入后第二天」与 T+1 一致：买入当日即使已经开板，也不能当天卖。

### 更贴近原话：开板当日收盘卖

用户说的是「收盘不涨停就卖」。引擎为了和页面其它策略一致，默认把卖出信号放到**次日开盘**。开板后经常次日低开，这一跳很贵：

| 出场价 | 笔数 | 胜率 | 平均单笔 | 中位数 | 盈亏比 |
| --- | ---: | ---: | ---: | ---: | ---: |
| **开板当日收盘卖** | 3,300 | 39.6% | **−0.88%** | −2.97% | 0.85 |
| 开板次日开盘卖 | 3,300 | 32.3% | −3.84% | −6.24% | 0.52 |

字面执行（开板收盘走）已经把亏损收窄到平均 −0.88%，**扣掉成本后仍是负的**。页面里点「生成代码 / 回测」走的是次日开盘，对应上表平均 −4.6%。

## 三、为什么多数单子只拿 2 天

| 持有天数 | 占比 |
| --- | ---: |
| 1 日 | 0.4% |
| **2 日** | **73.5%** |
| ≥5 日 | 4.9% |
| 最长 | 15 日 |

买入当日收盘仍涨停（接到第 4 板）的只有 **40.8%**。持有期间连续涨停根数（含买入当日）：

0 根 1957 笔 · 1 根 809 · 2 根 296 · 3 根 124 · ≥4 根 118

也就是说：**约 6 成买在第四日开盘后，当天就已经开板。** T+1 不能卖，第二天收盘多半仍不是涨停，第三天开盘才走——中间常常再吃一根跌停或大面。

典型反例：000002 万科 A，2024-09-26/27/30 三连板，10-08 开盘 10.69 买入（第四日高开后收盘 +6.8% 未封住），10-09 收盘 −10.0%，10-10 开盘 8.90 卖出，净亏损 **−16.9%**。若按「开板收盘就卖」在 10-09 收盘 9.34 走，仍亏约 −13%。

少数长连板能把账做正：603178 圣龙股份 2023-10-11 开盘买入后连板到 10-25，10-26 开板（−7.1%），10-27 开盘卖出，持有 12 日、**+141.7%**。这类票补不回 1957 笔「当天就开板」的亏损（盈亏比 0.46）。

## 五、结论

1. **比「跌破 10 日线」好，但不是正期望策略。** 引擎口径平均 −4.60%，字面「开板收盘卖」平均 −0.88%。
2. **73% 的交易只持有 2 天**——买在第四日开盘，当天或次日开板，再隔一夜才卖得掉。
3. 长连板的大赢家真实存在，但数量太少（持有 ≥5 日不足 5%），填不平开板大面。
4. 页面策略库已加入编号 32。页面回测用的是**开板次日开盘卖**；若要按原话在开板收盘离场，数字会接近 −0.88%，不是页面里的 −4.6%。
