# 30 个 A 股常用量化策略 · 全市场 5 年回测

对 30 个公开常用的 A 股技术类量化策略，在**全 A 股 × 最近 5 年**（2021-08-17 ~ 2026-08-17）
上逐个回测，保留每个策略的规则、生成的 Python 代码、逐笔交易、权益曲线与指标，并给出排序汇总。

结果总表见 [`summary.md`](summary.md)；净值曲线见 `equity_curves.png`。

另有按需追加的专项回测：

- [`limitup3_report.md`](limitup3_report.md)——三连板后回踩10日线（用户指定原策略）
- [`limitup32_report.md`](limitup32_report.md)——三连板后持有到开板（涨停继续拿、收盘不涨停就卖）
- [`limitup_optimize_report.md`](limitup_optimize_report.md)——连板票多维度优化（市值/换手/成交额/行业/大盘、追板 vs 回调、S4 过拟合警示、S12 大样本改善）
- [`overnight_report.md`](overnight_report.md)——隔夜持股法（尾盘买、次日开盘卖）网上方案调研与全市场回测

## 回测口径

- 撮合：**收盘后产生信号 → 次日开盘价成交**；买入价上浮滑点、卖出价下浮滑点；T+1 后才可卖出；
  一字涨跌停（开=高=低=收 且 |涨跌幅|>9.5%）当日不成交
- 成本：手续费 0.5‰ + 滑点 0.5‰，**双边**，单次往返约 2.0‰
- 样本处理：区间内新上市的标的跳过上市后前 60 根 K 线（次新期）；总 K 线不足 30 根不参与
- 两种度量口径（同一批信号、同一套退出规则）：
  - **A 信号级等权**：每个买入信号都等额成交、不设持仓数量上限。不受「候选多于仓位时先挑谁」
    这一人为规则影响，是衡量策略本身胜率与单笔收益的口径；并按「当日所有在持仓位等权、每日
    再平衡」合成净值曲线用于算年化/回撤/夏普
  - **B 资金约束组合**：1000 万本金、单笔 5%、最多同时持 20 只。与页面生成的 Python 代码逐笔一致；
    另跑一版「候选随机挑选」以量化分配规则的影响
- 基准：全市场等权买入持有 5 年 +42.41%（中位数 +3.83%，上涨个股占比 52.6%）

## 与页面 App 的关系

30 条策略的中文规则全部由 `stock-quant-backtest.html` 内置的中文策略编译器翻译成 Python
回测代码（`strategies/*.py`），页面「策略库」下拉里可以直接选中同样的 30 条规则复跑。

`engine_np.py` 是为了跑全市场而写的 numpy 版引擎；它与「生成的 Python 代码」的等价性由
`parity_check.py` 逐笔校验：**136 只标的子集、30 个策略、累计 39356 笔交易，代码、买卖日期、
成交价、股数、收益率、卖出原因全字段完全一致**（`parity_report.json`）。为此 numpy 侧刻意采用
与生成代码相同的浮点累加顺序——A 股价格常出现 MA 完全相等的临界情形，累加顺序不同会让
`MA5 > MA20` 这类严格比较在最后一位翻转。

## 结论要点

1. 这 5 年里**均值回归/超跌反弹类明显优于趋势突破类**：收益前 5 名全部是超跌反弹或缩量回踩
   （CCI 超卖 +52.5%、KDJ 低位金叉 +44.7%、BIAS+WR 共振 +43.9%、缩量回踩 20 日线 +40.7%、
   布林下轨反弹 +22.4%），而追涨类（涨停次日跟进 −96.0%、换手率突增 −89.2%、单日暴跌反弹 −83.8%、
   20 日新高放量突破 −81.0%）大幅亏损。这与公开研究里「A 股短期反转效应显著、动量效应弱」一致。
2. **只有 5 个策略跑赢等权买入持有基准（+42.4%）中的前两名**，且都没有明显超额；把交易成本
   算进去后，多数常用单指标策略在全市场层面并不赚钱。
3. **胜率与收益率不是一回事**：布林下轨反弹胜率最高（56.95%）但收益只有 +22.4%；MACD 金叉死叉
   平均单笔 +0.91%（第 3 高）却因胜率低（37%）与持有期长，5 年只有 +5.8%。
4. **资金约束下「先挑谁」比策略本身影响更大**：同一策略在「成交额优先」与「随机挑选」两种分配
   规则下的 5 年收益能差 30~90 个百分点（如缩量回踩 20 日线 −70.4% vs +18.2%）。因此表三只能
   作为参考，跨策略比较应看表一/表二的信号级口径。
5. 单笔仓位固定为**初始资金**的 5%（页面引擎的口径）在净值下跌后不会同步缩小仓位，会放大回撤，
   这也是表三普遍难看的原因之一。
